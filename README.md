**Tech:** Expo, React Native, TypeScript, Open-Meteo API, expo-notifications, expo-router

### Zenvoy
A React Native receipt scanning and expense management app. Users capture receipts with their camera, which are parsed by Claude AI, stored locally in SQLite, and synced to Firebase. Includes offline support, spending analytics, PDF/CSV export, full-text search, and cloud sync conflict resolution.

**Tech:** React Native, Expo, Claude AI API, Firebase Auth, Firestore, SQLite, expo-image-picker

[GitHub](https://github.com/aayanareejo1/Zenvoy)
